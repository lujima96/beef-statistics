# Beef Stats Frontend (Vite + React + TypeScript)

This is a minimal scaffold for the Beef Stats SPA. It uses Vite, React, and TypeScript.

## Quick start

- Install deps: `npm install`
- Run dev server: `npm run dev`
- Build: `npm run build`
- Preview build: `npm run preview`

## Structure

- `index.html` — app entry
- `src/main.tsx` — React bootstrap
- `src/App.tsx` — placeholder app component
- `src/index.css` — global styles
- `public/vite.svg` and `src/assets/react.svg` — icons
- `vite.config.ts` — Vite config with React plugin
- `tsconfig*.json` — TypeScript configs
