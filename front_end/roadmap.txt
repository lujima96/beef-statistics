SPA Component Roadmap (Frontend Only — Build UI First)

Note: Focus on components/pages and mock data. Wire API later.

1) App Shell & Routing
   - Create `App.tsx` with layout (Header, Nav, Main Outlet).
   - Add React Router routes: `/dashboard`, `/boxed`, `/primals`, `/trimmings`, `/index`, `/catalog`.

2) Header
   - Contains: Logo/Title, DateRangePicker (presets: 1M/3M/YTD/1Y/Max), RunToggle (AM/PM/Both), RegionToggle (Central/National), Compare toggle.
   - Sticky at top; emits events to update URL params.

3) Navigation
   - Tab or sidebar nav linking to routes above.
   - Highlight active route; keep URL state intact.

4) Global Filter State + URL Sync
   - Read/write filters from URL search params (`from`, `to`, `run`, `region`, `compare`).
   - Persist last-used filters in `localStorage` as fallback.

5) Shared UI Primitives
   - DateRangePicker: calendar + quick presets.
   - RunToggle, RegionToggle: segmented controls.
   - SeriesPicker: multi-select for primals/leans.
   - KPICard: label, value, delta (day/week), optional sparkline.
   - Empty/Skeleton states.

6) Chart Primitives
   - TimeSeriesChart: line/area with crosshair and tooltip.
   - VolumeBars: stacked bars (loads/pounds) under chart.
   - MultiAxisChart: price + volume/spread on secondary axis.
   - Indicator overlays: simple SMA/EMA (client-computed over mock data).

7) Dashboard Page (`/dashboard`)
   - KPICards: Choice, Select, Spread, Key Trimmings (50/65/85/90), Total Loads.
   - Main chart: Choice vs Select + 7/30 SMA + volume bars.

8) Boxed Page (`/boxed`)
   - Controls: show/hide Select, show spread band, toggle volume.
   - Chart: Choice vs Select; spread as area band; volume bars.
   - Sidebar KPIs: latest values and day-over-day change.

9) Primals Page (`/primals`)
   - Controls: SeriesPicker (rib, loin, chuck, round, brisket, short plate, flank); show choice/select.
   - Chart: multiple lines; legend toggles per series.
   - Mini-cards: latest per selected primal.

10) Trimmings Page (`/trimmings`)
   - Controls: SeriesPicker (50/65/73/81/85/90), RegionToggle; toggle loads/pounds.
   - Chart: lines per lean; optional secondary axis for loads/pounds.

11) Index Page (`/index`)
   - Controls: toggle choice/select index, headcount, dressing %, costs, drop credit.
   - Chart: index price lines; secondary lines/bars for supporting metrics.

12) Catalog Page (`/catalog` and `/catalog/:date`)
   - Daily cards: cutout, spread, key primals, key trimmings, slaughter/production.
   - Deep links to other pages with date preselected.

13) Compare Mode (global)
   - Overlay prior period (e.g., same range last year) on charts.
   - Visual diff: color-coded delta, optional percent-change toggle.

14) Snapshots (client-only initially)
   - Save current filters + visible series to `localStorage`.
   - Snapshots panel: list, apply, delete.

15) Theming & Accessibility
   - Light/dark theme; colorblind-friendly palette.
   - Keyboard navigation for charts and filters; descriptive tooltips.

16) Mocks & Types
   - Define TS types for series points and cards.
   - Provide `mockData.ts` per page to develop charts without API.

17) Testing & Polish
   - Add unit tests for formatters and reducers.
   - Visual checks for charts and states (loading/empty/error).
