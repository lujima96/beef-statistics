Simplified ER Diagram — One Table per JSON Category
===================================================

Each table stores the entire JSON document for a report in a single row (payload jsonb), plus a few convenience columns.

+----------------------------+
| boxed_am_reports_json      |
| id (PK)                    |
| report_id (TEXT, nullable) |
| report_date (DATE)         |
| run (run_enum='AM')        |
| source_file (TEXT)         |
| payload (JSONB)            |
| created_at (timestamptz)   |
+----------------------------+

+----------------------------+

Notes
- No foreign keys or child tables; each row represents a complete JSON record.
- Add unique constraints per feed, e.g., (report_id, report_date, run) or (report_code, report_date, run).
- Add expression indexes on payload fields you query frequently.
